# 온라인 코딩 프로세스 개발
- 프로젝트 명 : onCoTe2

## 목적
- 온라인 기반 코딩 프로세스 개발을 통해 다양한 웹 기반 개발 기술의 학습 및 사용 경험 습득

## 기술 스택
- Frontend
    - Svelte or React
- Backend
    - Nest.js
- Database
    - MongoDB or Mariadb
- Infra
    - Docker, k8s
- Redis

## 플로우
1. 로그인
    - OAuth, 자체 데이터 관리 (권한 레벨 부여)

1. 서비스 구성
    - 기능 구성
        - 코딩 및 실행
        - 문제 제공
        - 문제 제작

1. 인프라 구성

## 과정 (┃ ━ ┣ ┫ ┳ ┻ ╋ ┏ ┓ ┗ ┛)
### 관리자
~~~
로그인
┃
메인 화면
┣ 문제 제작
┣ 시험 제작
┣ 시험 감독
┣ 시험 결과
~~~

### 응시자
~~~
로그인
┃
메인 화면
┣ 시험 응시
┣ 응시 결과
~~~

1. 로그인
